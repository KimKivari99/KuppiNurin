# KuppiNurin — Project Wiki

**KuppiNurin** ("Cup Upside Down") is a static website for *Kahvila KuppiNurin*, a fictional Finnish coffee shop located in Nummela.

> "Niin hyvää, että menee kuppi nurin!" — So good it turns the cup upside down!

🌐 **Live site:** [kimkivari99.github.io/KuppiNurin](https://kimkivari99.github.io/KuppiNurin/)
